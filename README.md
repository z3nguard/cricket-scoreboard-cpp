# Cricket Scoreboard System

A simple C++ cricket scoreboard system that simulates a two-innings cricket match.

## Features

- Team name input
- Random toss system
- Bat or bowl decision
- Run scoring
- Singles and doubles
- Extras
- No balls
- Wickets
- Live scoreboard
- Target display in the second innings
- Automatic match result

## Technologies Used

- C++
- Dev-C++
